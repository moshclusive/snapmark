# Contributing

Thank you for wanting to improve this project! Contributions are welcome - bug fixes, small improvements, documentation, and new features that fit the tool's purpose.

## How to contribute

1. **Fork** this repository.
2. Create a branch for your change: `git checkout -b fix/short-description`
3. Make your change. Keep it focused - one fix or feature per pull request.
4. Test it if you can, and describe how you tested it in the pull request.
5. Open a **Pull Request** against the `main` branch and explain:
   - What you changed and why
   - How to reproduce / verify it

Small pull requests are easier to review and merge. If you are planning a large change, please open an Issue first to discuss it.

## Reporting a bug

Open an Issue with:
- What you expected to happen
- What actually happened
- Steps to reproduce
- Your OS / browser / app version, and screenshots if helpful

## Questions

Open an Issue - that keeps the answer visible for the next person with the same question.
